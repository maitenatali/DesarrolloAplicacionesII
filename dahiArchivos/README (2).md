# Flujos de datos — UADEnet

Convenciones de los documentos: cada flujo indica **Módulo Externo**, **Dirección** (Entrada / Salida), **Canal** (REST, Message Queue, etc.), **Identificador** (endpoint o evento), **Estructura** y **Ejemplo**. Ojo: no todos los grupos usan la misma lectura de «Dirección»; cada archivo aclara la suya al principio.
