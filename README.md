# Primer entrega - Desarrollo de Aplicaciones II

Proyecto con prototipos de interfaz en HTML para una plataforma educativa institucional.

## Descripción

Este repositorio contiene una serie de pantallas diseñadas para una aplicación web de gestión académica, incluyendo:

- Login y recuperación de contraseña
- Dashboard
- Mis cursos
- Crear curso
- Detalle de curso
- Gestión de estudiantes y asistencia
- Exámenes y actas
- Calendario
- Notificaciones
- Compras y saldo
- Cuenta institucional
- Perfil docente

## Cómo ver el proyecto

Simplemente abre cualquiera de los archivos HTML en tu navegador.

Por ejemplo:

- `pantalla-01-login.html`
- `pantalla-02-dashboard.html`
- `pantalla-27-perfil-docente.html`
